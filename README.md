# Projeto-1A
# 🌾 Festejando a Conexão Campo-Cidade 🌆

Uma plataforma web educativa e interativa desenvolvida para celebrar e conscientizar sobre a relação de interdependência entre o meio rural e o urbano. O projeto foi desenhado com foco em usabilidade e gamificação, sendo ideal para públicos de todas as idades.

---

## 🎯 Objetivos do Projeto
* **Educar:** Mostrar como o campo alimenta a cidade e como a cidade moderniza o campo.
* **Engajar:** Utilizar um minijogo interativo para fixar o conhecimento de forma divertida.
* **Acessibilidade:** Interface limpa, responsiva e de fácil leitura para crianças e adultos.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as três tecnologias pilares do desenvolvimento web front-end:

* **HTML5:** Estruturação semântica das seções (Início, Importância, Jogo e Rodapé).
* **CSS3:** Design moderno, paleta de cores temática (Verde/Azul) e efeitos visuais suaves.
* **JavaScript (Vanilla):** Lógica do "Jogo da Origem", validação de respostas e transição dinâmica de conteúdo.

---

## 🎮 Funcionalidades
* **Navegação Suave:** Menu que ancora diretamente nas seções da página.
* **Minijogo "De onde vem?":** O usuário testa seus conhecimentos clicando na origem correta dos itens, recebendo feedback educativo instantâneo.
* **Design Limpo:** Uso de cards informativos que facilitam a leitura rápida do conteúdo.

---

## 🚀 Como Executar o Projeto

1. Faça o clone deste repositório ou baixe os arquivos.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estão na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
